# 🏓 Ping Pong Game – C# Windows Forms

A simple yet interactive **Ping Pong desktop game** developed using **C# Windows Forms** in **Visual Studio Code**. This project demonstrates the fundamentals of **2D game development**, including collision detection, keyboard input handling, score management, and real-time game mechanics.

---

# 📌 Project Overview

This project recreates the classic **Ping Pong (Pong)** arcade game where players control paddles to hit a moving ball and score points against the opponent. The game was built to practice:

- Event-driven programming
- Real-time rendering and movement
- Object-oriented programming concepts
- Windows desktop application development
- Game logic implementation in C#

The application provides a lightweight and responsive gaming experience using the Windows Forms framework.

# 🎮 Gameplay

- Player controls the paddle using keyboard keys.
- The ball continuously moves across the screen.
- If the paddle misses the ball, the opponent gains a point.
- The game continues until a predefined winning score is reached.

---

# ⌨️ Controls

| Key | Action |
|-----|--------|
| `W` / `Up Arrow` | Move paddle up |
| `S` / `Down Arrow` | Move paddle down |
| `Enter` / `Space` | Restart game *(if implemented)* |

# 🧠 Concepts Implemented

This project demonstrates several important programming concepts:

## 1. Event-Driven Programming
Used keyboard events and timers to control gameplay and updates.

## 2. Collision Detection
Implemented logic to detect:
- Ball-to-paddle collisions
- Ball-to-wall collisions

## 3. Game Loop Logic
A timer continuously updates:
- Ball position
- Paddle movement
- Score conditions

## 4. Object-Oriented Programming
Organized code using classes, methods, and reusable logic.
